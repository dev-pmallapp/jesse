# Credential Management Reference

This fork (NSE/BSE-only) does not currently support live trading or custom data imports. Credential management is kept for internal use and future extensibility.

No tool ever returns a stored secret. Read tools return masked values or configuration status.

## Note

This fork only supports NSE/BSE spot equity backtesting on daily and weekly bars. Live trading on crypto exchanges and custom data imports via Massive have been removed, so credential management tools are deprecated and kept only for backward compatibility.
